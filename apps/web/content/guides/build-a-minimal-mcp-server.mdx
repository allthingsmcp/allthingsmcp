## Who this guide is for

Use this guide if you know basic Python and want the smallest local MCP server you can run and inspect. You will need Python, uv, and a terminal. The goal is to see one working tool end to end before adding other capabilities or deployment concerns.

## What you will build

You will set up an isolated project, create a FastMCP server, expose a typed addition tool, and connect with MCP Inspector. The last step checks initialization, tool discovery, and invocation so you can tell whether the client and server actually communicate.

This guide uses the [2025-11-25 MCP specification](https://modelcontextprotocol.io/specification/2025-11-25) and a local standard input/output connection. It does not cover remote transport, authorization, persistence, or hosting. For a broader TypeScript workspace with tools, resources, prompts, and export, use [Building Your First MCP Server](/guides/building-your-first-mcp-server).
