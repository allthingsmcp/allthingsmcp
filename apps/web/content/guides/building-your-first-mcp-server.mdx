## Who this guide is for

Start here if you want to understand MCP by building a server, rather than only reading about its parts. No previous MCP work is required. Familiarity with TypeScript helps when you inspect the generated source, but the browser activities guide you through each choice.

## What you will build

You will configure a weather server with tools, resources, and prompts, then connect the ATM learning client to inspect the messages exchanged with the server. The Guide Runtime workspace runs the configured capabilities, so you can test a tool before exporting a runnable TypeScript project. Your configuration remains the source of truth across the steps.

The explanations and protocol examples target the [2026-07-28 MCP specification](https://modelcontextprotocol.io/specification/2026-07-28). Use this guide when you want a broader view of a server's capabilities. If you only need a small local Python example, [Build a Minimal MCP Server](/guides/build-a-minimal-mcp-server) is the shorter path.
