## Who this guide is for

Start here if you want to understand MCP by building a server, rather than only reading about its parts. No previous MCP experience is required. Familiarity with TypeScript helps when you read the generated code, but every choice happens in the browser.

If you'd like the concepts first, [What Is MCP? A Practical Introduction](/blog/what-is-mcp) explains them without any building. This guide works either way.

## What you will build

You'll build a weather server that offers two tools, a resource and a prompt, then connect a client to it and test it. By the end you'll have:

- a server that returns live forecasts from Open-Meteo through MCP
- read every message a client and server exchange, field by field
- called a tool yourself, including one call that fails on purpose
- a TypeScript project you can run on your own machine and connect to a real AI app

The explanations and protocol examples target the [2026-07-28 MCP specification](https://modelcontextprotocol.io/specification/2026-07-28).

## How the workspace works

Each step has an interactive panel with four tabs:

| Tab          | What it shows                                                             |
| ------------ | ------------------------------------------------------------------------- |
| **Visual**   | The choices you make: the server name and what it offers                  |
| **Code**     | The TypeScript server the guide generates from those choices              |
| **Protocol** | Every MCP message sent so far, with the request and response side by side |
| **Client**   | The ATM learning client, which connects to your server and calls it       |
