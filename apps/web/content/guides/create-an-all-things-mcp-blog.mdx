An All Things MCP blog post is an MDX file: metadata at the top, followed by the article in Markdown. This Guide takes you from a focused idea to a review-ready post using the same article layout and cards as the rest of the blog.

You will create one article file, connect an author profile, and inspect the result locally. The site supplies the title, byline, table of contents, dates, and navigation. Publishing happens through the repository and deployment workflow.

If your contribution needs ordered tasks with a checkpoint after each one, use [Create an All Things MCP Guide](/guides/create-an-all-things-mcp-guide) instead.
