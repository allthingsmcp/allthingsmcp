## Who this guide is for

Use this guide when you want to contribute an ordered, hands-on workflow to All Things MCP. It assumes basic Markdown, Git, and GitHub familiarity, plus a local clone of the repository. Readers looking for a single explanatory article should use [Create an All Things MCP Blog](/guides/create-an-all-things-mcp-blog) instead.

## What you will produce

You will define a verifiable outcome, write an overview and matching step files, use the reviewed MDX components, and run the project checks before opening a pull request. The overview manifest connects step IDs, order, prerequisites, resources, and technical metadata; each step then gives the reader a concrete action and checkpoint.

This is the authoring reference for the site's current Git-based content workflow. The protocol-version field in a technical Guide identifies the specification its claims target; set it from the material you actually verify, rather than copying this example's value.
