The current protocol revision is `2025-11-25`. Its published changelog highlights authorization discovery, incremental scope consent, metadata icons, tool-name guidance, elicitation updates, polling behavior, and JSON Schema 2020-12 as the default schema dialect.

## Why it matters

Implementers should review feature-specific changes rather than treating a version label as a complete compatibility claim. Authorization and schema behavior deserve particular attention when moving from the prior revision.
