The ATM learning client is a deterministic browser simulation. Connecting it demonstrates how a current client discovers the server and lists the capabilities you configured.

<InteractiveGuideBlock scene="connect-client" />

After connecting, open **Protocol** and inspect `server/discover`. The request carries the current protocol metadata, while the response advertises the server identity and capability families.

<Callout title="This is the modern protocol flow">
  This Guide targets MCP `2026-07-28`. It intentionally does not show the older
  initialize-based connection sequence.
</Callout>
