The ATM learning client uses the same Streamable HTTP MCP handler as external clients. Connecting it performs `server/discover`, followed by tools, resources, and prompts discovery against your workspace.

<InteractiveGuideBlock scene="connect-client" />

After connecting, open **Protocol** and inspect `server/discover`. The request carries the current protocol metadata, while the response advertises the server identity and capability families.

<Callout title="This is the modern protocol flow">
  This Guide targets MCP `2026-07-28`. Each request includes the protocol
  version, client identity, and client capabilities in its metadata.
</Callout>
