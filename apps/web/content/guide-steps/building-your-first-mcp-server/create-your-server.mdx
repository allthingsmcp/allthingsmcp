Begin with a named server boundary. The name becomes part of the server identity shown to clients and the downloaded project package.

Use a lowercase, hyphenated name. The default `weather-server` is deliberately descriptive and portable.

<InteractiveGuideBlock scene="create-server" />

<Callout title="Browser-local for now">
  Creating the server configures the Guide simulation. It does not provision a
  process, endpoint, credential, or cloud resource.
</Callout>

Switch to **Code** after creating the server. The generated source should already contain a current SDK v2 server factory even though it exposes no capabilities yet.
