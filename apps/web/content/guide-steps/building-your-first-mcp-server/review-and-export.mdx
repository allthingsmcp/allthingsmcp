## 2. Run the exported project

Download the project, extract the ZIP and run it. You need Node.js 20 or newer.

```bash title="Terminal"
npm install
npm start
```

The terminal prints the address your server is listening on:

```text title="Output"
MCP server available at http://127.0.0.1:3001/mcp
```

This is the same server you tested, now running on your own machine. It speaks Streamable HTTP at a single `/mcp` URL, like the workspace did. It only accepts requests addressed to your own computer, which stops web pages you visit from reaching it. Set the `PORT` environment variable to use a different port.

The exported project calls Open-Meteo directly, so it needs an internet connection.

## 3. Connect a real host

To use the server from an AI app, add it to that app's MCP settings. Hosts connect to servers in one of two ways:

- **By URL, over Streamable HTTP.** Give the host `http://127.0.0.1:3001/mcp`. This is the transport your exported project uses.
- **By launching a program, over stdio.** Many desktop apps start local servers themselves and talk to them through standard input and output. Your exported project doesn't use stdio, so for these apps you'd need to add a stdio entry point first.

Once connected, ask the host's model something like "Do I need an umbrella in Lagos tomorrow?" and watch it choose `get_forecast` on its own. That's the part you played by hand in step 7.

<Callout title="Connect an external client to your workspace">
  You can also connect an external client to the hosted workspace instead of

  bearer token. Save the token when it is shown, because rotating or revoking it

  requests.

## What to learn next

Your server covers the core of MCP. Two parts of the protocol go further than this guide:

- **Servers that ask questions.** A server can answer a call with `input_required` and ask the user for more information, such as which Lagos they meant. [What Is MCP? A Practical Introduction](/blog/what-is-mcp) shows how that exchange works.
- **Calls that take minutes.** When a tool runs too long for one request, a server can return a task and report progress until the work is done. [Build Your First MCP Task](/guides/build-mcp-tasks-with-sharp) builds one step by step.
