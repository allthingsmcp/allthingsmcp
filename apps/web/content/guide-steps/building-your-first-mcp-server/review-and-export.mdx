Your visual configuration, generated source, protocol history, and test result should now describe the same server. Review that consistency before exporting the project.

<InteractiveGuideBlock scene="completion" />

## Run the exported project

Extract the ZIP, then run:

```bash title="Terminal"
npm install
npm start
```

The local project exposes a Streamable HTTP MCP endpoint at `http://127.0.0.1:3001/mcp` with loopback host and origin validation. Set the `PORT` environment variable to use another port.

<Callout title="Connect an external client">
  Sign in to claim and keep your workspace, then create an access token above.
  Configure your MCP client with the displayed endpoint and bearer token. Save
  the token when it is shown; rotating or revoking it disables the old token.
  Pausing the endpoint immediately prevents new MCP requests.
</Callout>

Weather results use live Open-Meteo data and include attribution. The exported project also calls Open-Meteo and requires an internet connection.
