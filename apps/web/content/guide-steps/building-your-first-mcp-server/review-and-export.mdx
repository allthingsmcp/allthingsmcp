Your visual configuration, generated source, protocol history, and test result should now describe the same server. Review that consistency before exporting the project.

<InteractiveGuideBlock scene="completion" />

## Run the exported project

Extract the ZIP, then run:

```bash title="Terminal"
npm install
npm start
```

The local project exposes a Streamable HTTP MCP endpoint at `http://127.0.0.1:3000/mcp` with loopback host and origin validation.

<Callout title="Hosted workspaces come later" type="warning">
  ATM does not host this server or issue credentials in this phase. The disabled
  hosted-endpoint and external-client actions mark the future Workspace API
  boundary without pretending that it exists.
</Callout>
