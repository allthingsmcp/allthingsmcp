Tools are operations a client can ask the server to perform. Their names, descriptions, and schemas should give both people and models enough information to invoke them correctly.

Start with **Get current weather**. Review its `location` and `unit` fields before adding it, then select another tool from the curated catalog to compare its schema.

The simulation uses deterministic weather data. No external weather provider is contacted.
