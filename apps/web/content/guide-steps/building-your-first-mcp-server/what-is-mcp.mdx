In this guide you'll build a weather MCP server, connect a client to it and watch the real protocol messages go back and forth. This step shows how the pieces fit before you start, so that every later step has a place in the picture.

## The three participants

Every MCP setup has three roles. The **host** is the AI app a person uses. Inside it, an **MCP client** keeps a connection to one **MCP server**, and the server offers capabilities such as tools.

![The host is the AI app you use. It runs the language model integration and decides what the model sees. Inside the host are two MCP clients, one per server. MCP client 1 connects over stdio to a files server running as a local process on the same machine; that server reads files on your computer. MCP client 2 connects over Streamable HTTP to a weather server running as a remote service; that server calls a weather API. Solid dark lines are MCP connections. Grey lines are each server's own access to its data, which is not MCP.](/images/blog/what-is-mcp/architecture.svg)

The model never talks to a server directly. It works inside the host, and the host decides which requests go out. In this guide there is no model and no chat app, so the roles are played like this:

| Role           | In a real app                            | In this guide                                             |
| -------------- | ---------------------------------------- | --------------------------------------------------------- |
| **Host**       | A chat or coding assistant               | The ATM learning client in the **Client** tab             |
| **MCP client** | A component inside the host              | Built into the ATM learning client                        |
| **MCP server** | A program the host connects to           | Your weather server, running in a Guide Runtime workspace |
| **Model**      | Chooses which tool to call and with what | You. You pick the tool and type its arguments in step 7.  |

## What your server will offer

An MCP server offers three kinds of capability. The difference that matters most is who decides when each one is used:
