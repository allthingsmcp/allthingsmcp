Prompts are reusable templates that a user can select explicitly. Arguments make one template useful across different places and days without hiding its intent.

Select **Plan for weather** and inspect its arguments and template text before adding the predefined prompt to your server.

<InteractiveGuideBlock scene="add-prompts" />

<Callout title="Write templates for inspection">
  Keep the prompt understandable before its arguments are substituted. A host
  should be able to show users what the template is designed to accomplish.
</Callout>
