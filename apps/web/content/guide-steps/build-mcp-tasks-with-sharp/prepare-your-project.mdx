In this step you will set up the local project that the rest of the guide builds
on. You will run the MCP server and the MCP client in separate terminals, both
from the same project folder.

## 1. Check the prerequisites

You should already have built an MCP server, registered a tool, and called it
from an MCP client. The examples also assume that you are comfortable with
asynchronous JavaScript and can read TypeScript. You don't need any previous
experience with Tasks.

Have a code editor and two terminals ready. Everything runs locally, so you
don't need an API key or an AI application.

| Software                                  | Check            | Version used here |
| ----------------------------------------- | ---------------- | ----------------- |
| [Node.js](https://nodejs.org/en/download) | `node --version` | `v24.21.0`        |
| [pnpm](https://pnpm.io/installation)      | `pnpm --version` | `10.20.0`         |

Use these versions so that your setup matches the one this guide was tested on.
The package scripts run the TypeScript files directly.

This walkthrough targets the **2026-07-28 Tasks extension**, whose messages
differ from older experimental Tasks examples. Keep the supplied `package.json`
and lockfile together, because between them they pin the MCP SDK client and
server at 2.4.0, the Tasks extension at 0.2.2, the Node adapter at 2.1.2 and
Sharp at 0.35.5.

## 2. Download and install the starter

[Download the starter](/downloads/mcp-tasks-thumbnails/starter.zip), extract it,
and open the `mcp-tasks-thumbnails` folder in your editor. From that folder, run:

```bash
pnpm install --frozen-lockfile
pnpm run fixtures
pnpm run verify
```

The last two commands generate the input images and then check them. Apart from
pnpm's script headers, you should see these lines:

```text
Ready: 6 sample images and 1 deliberate error fixture.
Node 24.21.0; Sharp 0.35.5; 6 images verified.
```

If Sharp fails to load, check your Node version and run the installation again
in this folder. The [Sharp installation guide](https://sharp.pixelplumbing.com/install/)
explains errors that are specific to a platform. If an image is missing, run
`pnpm run fixtures` again.

The [completed project](/downloads/mcp-tasks-thumbnails/completed.zip) is
available if you want to compare your work, but you only need the starter to
build along. If you get stuck, the recovery downloads at the end of the setup
and coding steps let you pick up from that point. Extract one into a new folder,
then install the dependencies and regenerate the fixtures there.

## 3. Locate the Tasks integration points

Open `fixtures/landscape.png` to see one of the sample images. The supplied Sharp
function in `src/resize-image.ts` creates WebP copies of an image at 320, 640 and
1280 pixels wide, and `src/thumbnails.ts` repeats that for all six images and
records the outputs in `manifest.json`. These helpers are already written so that
you can concentrate on MCP Tasks.

You will write four files:

| File                      | What you will implement                                       |
| ------------------------- | ------------------------------------------------------------- |
| `src/app.ts`              | Tool registration and the Tasks handler hook.                 |
| `src/task-handlers.ts`    | Task creation, status retrieval and cancellation.             |
| `scripts/tasks-client.ts` | An MCP client that declares Tasks support and calls the tool. |
| `src/watch-task.ts`       | The loop that checks status and returns the result.           |

The starter also supplies the HTTP wiring, message validation and a file-based
worker and store. These are project helpers whose code you can read, and they are
not extra SDK methods. The files marked `TODO` are the ones you will complete in
steps 3 and 4.

**Checkpoint:** the pinned dependencies are installed, and verification finds six
readable input images. `broken.png` is invalid on purpose. You will use it to
test tool-error handling in the final step.

[Recover to the end of step 2](/downloads/mcp-tasks-thumbnails/step-2.zip).

The commands were checked on macOS arm64 on **31 October 2026**. Linux CI is
configured but has not been observed running, and Windows is untested. The
53-minute length of this guide is an editorial estimate that still needs a
run-through by a developer who is new to Tasks.
