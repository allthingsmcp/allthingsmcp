Add a tool between the `FastMCP` instance and the run block:

```python title="server.py" lineNumbers
from mcp.server.fastmcp import FastMCP

mcp = FastMCP("mcp-server-demo")


@mcp.tool()
def add(a: int, b: int) -> int:
    """Add two integers and return the result."""
    return a + b


if __name__ == "__main__":
    mcp.run()
```

## What the decorator contributes

The decorator registers `add` as a tool. The SDK uses the function name, type annotations, and docstring to construct the tool description and input schema exposed to clients.

This first tool is intentionally deterministic and side-effect free. It lets you verify discovery and invocation without introducing credentials, network calls, or destructive behavior.
