The Authorization Flow Explorer is planned. It will help developers trace protected-resource discovery, authorization-server discovery, PKCE, resource indicators, access-token use, and step-up authorization without hiding the standards behind an oversimplified animation.

There is no non-functional “Open tool” action. Contribute use cases and edge cases through the public repository.
