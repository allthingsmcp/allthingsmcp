# Brand constitution

## Current identity

Open Junction (iteration 02) is the approved mark: an open rounded-diamond hub, three circular terminals, equal branches, and the custom P counter in the outlined Geist wordmark. Use the supplied masters and [logo usage guidance](logo-usage.md); never redraw the symbol or retype the wordmark. Positioning: **Learn. Build. Ship with MCP.**

## Character

All Things MCP is an independent developer field guide: technically exact, calm, legible, and practical. The visual signature is protocol structure made visible through diagrams, relationship lines, precise metadata, and editorial hierarchy.

## Tokens

- Canvas: `#ffffff`; subtle surface: `#f8fafc`; dark surface/navy: `#0f172a`.
- Text: `#0f172a`; secondary text: `#3e4c66`; muted text: `#53657b`.
- Action/logo blue: `#2563eb`; deep blue: `#1d4ed8`; pale blue: `#eff6ff`; on-dark logo/accents: `#60a5fa`.
- Semantic green: `#0b9f5a`; violet: `#7047eb`; orange: `#dc6925`.
- Border: `#dce4ee`; stronger border: `#c9d2e1`.
- Radii: 6px controls, 10px cards, 14px major panels.
- Shadows: only subtle elevation on interactive overlays and featured panels.
- Spacing: derive from an 8px foundation, with 4px half steps for compact metadata.
- Motion: 120–240ms UI transitions; no decorative sequence should exceed 600ms.

## Typography

- Display: Geist, 650–750 weight, compact leading, restrained tracking. The logo wordmark is supplied as outlined Geist 660 with custom spacing and a custom P; do not substitute live text.
- Body: Inter, 400–600 weight, 1.55–1.7 leading for long-form reading.
- Code/data: JetBrains Mono, 400–600 weight.
- Prefer sentence case. Use uppercase only for compact categories and statuses.

## Layout

- Desktop artboard: 1440px; content container: 1280px.
- Mobile reference: 390px.
- Use `Header → Main → Footer` consistently.
- Desktop grids may become lists, accordions, or horizontal scrollers on mobile; never merely scale them down.
- Use hairline dividers and generous section spacing to make dense material calm.

## Components

- Buttons: solid blue primary, white secondary with neutral border, text tertiary.
- Cards: low-radius, fine border, minimal shadow, one clear action.
- Badges: semantic pale fill with readable foreground; statuses must include text.
- Code: dark navy surface, language label, copy action, visible focus.
- Newsletter: pale blue framed panel with a direct-subscribe fallback.
- Footer: dark navy on long editorial pages; compact accordion groups on mobile.
