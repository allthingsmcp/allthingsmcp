# Interactive Guide feature inventory

The original Guide mockups have been retired because they contain obsolete
logo artwork. Preserve the feature semantics below using the existing reviewed
components and tests, not old screenshots or Git history. The brand-system
skill owns the current logo, typography, palette, and responsive shell.

| Area | Feature semantics |
| --- | --- |
| Cross-view consistency | A shared configured server across all views |
| Guide overview | Outcome, requirements, duration, learning goals, and progress |
| Tools | Predefined tool selection, schema inspection, add/remove behavior |
| Resources | Resource URI, MIME type, response preview, and configured state |
| Prompts | Predefined arguments, template inspection, and configured state |
| Code view | Read-only generated source and server summary |
| Protocol view | Message flow, event list, request/response inspector |
| Client view | Guided ATM client commands and structured results |
| Completion | Final review, learning summary, export, and next actions |

Do not use regenerated concept mockups as implementation references. Authored
Guide content, the runtime contracts, and the current application define actual
behavior; never present a mockup-only capability as working.
