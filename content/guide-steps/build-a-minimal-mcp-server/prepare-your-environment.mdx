Start with an isolated project so the server has an explicit dependency boundary and a reproducible launch command.

## Create the project

Run these commands in a terminal:

```bash title="Terminal"
uv init mcp-server-demo
cd mcp-server-demo
uv add "mcp[cli]"
```

The `cli` extra installs the development commands used later in this Guide.

## Confirm the SDK is available

```bash title="Terminal"
uv run mcp version
```

You should see the installed SDK version rather than a command-not-found error.
