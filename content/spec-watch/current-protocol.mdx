MCP `2026-07-28` is a breaking revision centered on a stateless protocol core. The change is more than a transport optimization: it alters request metadata, discovery, interaction patterns, routing, caching, and the boundary between the core and extensions.

## What developers need to do

Start with code that assumes an initialization exchange or an `Mcp-Session-Id`. Then review server-to-client requests, response result types, gateway behavior, client identity, and authorization issuer validation.

Do not claim July 2026 compatibility from a package version alone. Test the exact client, server, transport, and extension combinations you support.
