This path is for developers who want a durable mental model before reaching for an SDK.

## Outcomes

You will be able to identify MCP participants, explain initialization and capability negotiation, choose among resources, prompts, and tools, and inspect a basic connection.

## Lessons

1. What MCP standardizes
2. Hosts, clients, and servers
3. Connection lifecycle
4. Server and client features
5. Transports and deployment boundaries
