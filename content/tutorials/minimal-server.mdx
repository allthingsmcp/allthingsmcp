This representative tutorial establishes the structure future hands-on guides will follow: prerequisites, tested environment, complete code, verification, failure modes, and cleanup.

## Before you begin

Use a supported Python runtime and the current MCP Python SDK. For a local standard-input/output server, credentials should come from the process environment rather than the HTTP authorization flow.

## Build in small steps

<Steps>

### Create the server

Initialize one focused server and give it implementation metadata that a client can identify during initialization.

### Add one read-only capability

Expose a deterministic capability with a narrow schema. A first server should prove lifecycle and discovery before adding side effects.

### Inspect initialization

Connect with a development client and confirm the negotiated protocol version and capabilities before invoking the capability.

</Steps>
