# Getting help

- **Questions about MCP or a Guide:** open a GitHub Discussion if enabled, or an issue using the _Content correction or
  request_ template.
- **Bugs or feature ideas for the site:** open an issue with the _Platform feature_ template, or send a pull request.
- **Security issues:** follow [SECURITY.md](SECURITY.md); do not post them publicly.
- **Contributing:** see [CONTRIBUTING.md](CONTRIBUTING.md).

This is a community project maintained in spare time. Responses are best-effort.
