# All Things MCP

An independent, developer-first publication and learning platform organized around outcome-driven Guides, technical Blog analysis, and Spec Watch.

## Local development

```bash
pnpm install
pnpm dev
```

Copy `.env.example` to `.env.local` to configure the public site, repository, and Substack URLs. Content lives in `content/` and is validated with `pnpm content:validate`.
