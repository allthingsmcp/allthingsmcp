# All Things MCP

An independent, developer-first knowledge platform for learning, building, securing, and operating Model Context Protocol systems.

## Local development

```bash
pnpm install
pnpm dev
```

Copy `.env.example` to `.env.local` to configure the public site, repository, and Substack URLs. Content lives in `content/` and is validated with `pnpm content:validate`.
